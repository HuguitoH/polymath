## Output rules

- Use only the data inside <data> tags. State what is there; omit what is not.
- Skip any section that has no data, silently.
- Say less when there is less to say. Short is good.
- Write plain prose meant to be read aloud: sentences only, no lists, headers,
  markdown or symbols.
- Write numbers as speech: "just over half" rather than "58%".
- Offer at most one thing to revisit later.
- End with exactly one question.
- Write the way you would say it aloud to a friend, not the way you would
  write it down. No labels like "Notifications:" and no comma-separated lists
  standing in for sentences.
- Let each item be its own sentence with a verb.
